**सूत्र** — "thread". A notes app for materials-chemistry research that keeps
your notes as plain markdown files on your own disk.

This is the first public build. It is complete enough to write in every day,
and honest about what it does not yet do.

## Install

Download **`Sutra_0.1.0_x64_en-US.msi`** and run it. `Sutra_0.1.0_x64-setup.exe`
is the same application with the other installer; take whichever you prefer.

The installer is **not code-signed**, so Windows SmartScreen will warn you the
first time: click **More info → Run anyway**. Signing needs a certificate,
which is a decision about money and identity rather than a build step.

On first run Sutra asks for a folder to use as your vault. Any folder will do,
including one that already has markdown in it.

## What it does

- **Your notes are files.** Plain markdown with YAML frontmatter, in folders
  you chose, readable and editable by anything else. No database, no lock-in;
  put the folder in git, OneDrive or Dropbox and all three work well on it.
- **Maths and chemistry are first-class.** KaTeX with mhchem, so `$\ce{Sb2Se3}$`
  in a sentence and a full reaction on its own line both render as you type,
  and both round-trip to markdown unchanged.
- **Zotero, for real citations.** Search your library from inside a note, cite
  without ever inventing a key, and let Zotero's own CSL engine render every
  style it supports — ACS by default, because that is what these journals want.
  Works against the local connector or your Zotero account.
- **Source, evidence and interpretation stay apart.** What a paper says, the
  page it says it on, and what you think about it are different things, and the
  app never blurs them.
- **Links, backlinks and tags**, a command palette, saved views, and a context
  panel that shows what is near the note you are in.
- **Word and PDF export**, with equations rendered as images.
- **It is yours to look at.** Four themes in light and dark, your own fonts,
  and an editing toolbar you can dock to any edge.

## Known limits

Stated plainly, so none of them is a surprise:

- The installer is unsigned; SmartScreen will warn on first run.
- No version history — the file on disk is the current version.
- No OCR and no PDF text extraction. A PDF can be attached; its text is not
  indexed.
- No mobile app and no sync of its own. Sync the vault folder with whatever you
  already use.
- Folders go four levels deep, no further.
- Word export does not lay out a bibliography section. The reference list is
  rendered in your chosen style and can be copied; placing it is yours.
- An AI API key typed into the settings panel is stored in plain text in
  `sutra.json`. Use the `ANTHROPIC_API_KEY` environment variable instead if
  that matters to you. Assistance is off until you turn it on, and everything
  else in the app is computed locally from your vault.
