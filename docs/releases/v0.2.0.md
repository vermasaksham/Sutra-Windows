The second build, and a more trustworthy one than the first. Two bugs fixed
here could quietly cost you work; both were found by testing on Windows rather
than by reading the code.

## Install

Download **`Sutra_0.2.0_x64_en-US.msi`** and run it. `Sutra_0.2.0_x64-setup.exe`
is the same application with the other installer; take whichever you prefer.

Installing over 0.1.0 keeps everything — your vault is a folder of markdown
files and nothing in this build touches it. The installer is still not
code-signed, so SmartScreen warns on first run: **More info → Run anyway**.

## Two things that could have cost you work

**Opening the wrong copy of a note.** If a sync client left a conflicted copy
beside one of your notes, which of the two Sutra opened depended on the order
the filesystem happened to return them — and that order is not the same on
Windows as elsewhere. The same vault on your desktop and your laptop could open
different notes, and the one you got on Windows was the sync client's copy
rather than yours. Sutra now always opens the file it wrote. Neither copy is
hidden: both stay listed and readable, so you can compare them and delete the
loser yourself.

**A save refused while a sync client held the file.** On Windows, replacing a
file fails outright while another process has it open — and on a vault in
OneDrive or Dropbox, that process is the sync client scanning the file being
replaced. Saves now wait it out.

## Citations

**Numbered styles are numbered.** In ACS, RSC, Nature, IEEE or Vancouver, a
citation now reads `(1)`, `(2)` — the paper's place in the reference list, in
order of first appearance — and renumbers as you insert one ahead of another.
Author-date styles are unchanged and read exactly as your library renders them.

The bibliography is built from the same order, so `(3)` and the third entry are
always the same paper.

**Word export carries the formatting.** A journal name your style italicises
arrives italic instead of wrapped in asterisks.

## Writing

**Formulas are written in the line, not in a box.** Editing an inline formula
no longer opens a bordered input that changes the height of the line you are
part-way through. A chemical equation's source sits on its own line, unboxed.

Three faults went with it: choosing **Chemical equation** used to produce a
blank strip with no caret; the caret now lands inside `\ce{}` so you type only
the reaction; and finishing a formula no longer throws away the next sentence
you type.

**The editing toolbar stays with you.** Dock it to any edge and it follows the
note as you scroll — pinned under the status bar at the top, floating at the
bottom, or beside the text at either side, in a strip the note keeps clear so
it never covers the first character of a line.

## New

**Where the work is.** `Ctrl+K` → _Where the work is_ shows the questions you
have asked and not answered, the ones you have started, the sources nothing
cites, and how much of your evidence carries a page and the source's own words.
Counted from your vault; nothing ranked, scored or suggested.

**A version check.** Settings → Version tells you whether a newer Sutra exists.
A button, never a timer — nothing leaves your machine unless you press it.
Sutra still cannot install an update itself.

**Its own icon**, replacing the placeholder 0.1.0 shipped with.

## Faster

A vault of five thousand notes opens in under two seconds rather than not at
all. The note list renders as far as you scroll instead of building a row for
every note.

## Still not done

- **The installer is unsigned**, so SmartScreen warns. Fixing it needs a
  certificate.
- **Updates are not automatic.** Sutra can tell you; it cannot install.
- **No OCR or PDF text extraction**, no mobile app, no sync of its own, no
  version history beyond what you put the vault folder in.
- Numeric citations are numbered per note, not across a whole thesis.

Every one of these is stated in the manual too, in
[§20 Known limits](../manual.md).
